# Master Java for Competitive Programming

A structured Java repository for learning and practising **competitive programming**, with a focus on mastering Java fundamentals, mathematical operations, algorithms, data structures, and problem-solving techniques.

## 📚 Repository Contents

The repository contains Java source code and practice implementations covering different competitive programming concepts.

* Conditional Statements
* Loops
* Functions and Methods
* Arrays
* Strings
* Data Structures
* Algorithms
* Problem-Solving Techniques

More topics and practice problems will be added progressively.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MiniduOshan/Master-Java-for-Competitive-Programming.git
```

### 2. Navigate to the Project

```bash
cd Master-Java-for-Competitive-Programming
```

### 3. Compile a Java Program

```bash
javac src/YourFile.java
```

### 4. Run the Program

```bash
java -cp src YourFile
```

> The exact command may vary depending on the package structure and location of the Java file.
